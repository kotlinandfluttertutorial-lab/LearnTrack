- [ ] 13. Create `CourseRepository` interface and `CourseRepositoryImpl`.

       **`app/src/main/java/com/learntrack/data/repository/CourseRepository.kt`**
       - `interface CourseRepository { fun getTopics(): Flow<Result<List<Topic>>> }`

       **`app/src/main/java/com/learntrack/data/repository/CourseRepositoryImpl.kt`**
       - `class CourseRepositoryImpl @Inject constructor(private val context: Context) : CourseRepository`
       - `override fun getTopics(): Flow<Result<List<Topic>>>` implemented as:
         ```
         flow {
             val json = context.assets.open("learntrack_topics.json").use { it.bufferedReader().readText() }
             val container = Json.decodeFromString<TopicContainer>(json)
             val validated = TopicSchemaValidator.validate(container.topics)
             emit(Result.success(validated))
         }
         .catch { e ->
             Log.e("LearnTrack", "Failed to load topics", e)
             emit(Result.failure(e))
         }
         .flowOn(Dispatchers.IO)
         ```
       - Catch block handles `IOException`, `SerializationException`, `ValidationException` uniformly.
       - Verbose log line gated with `if (BuildConfig.DEBUG)`.

       Files: the two paths above.
       Verify: `cmd /c gradlew.bat compileDebugKotlin` exits 0.

         `calculateProgress(topics)` and emits `Result.success(Pair(progress, topics))`;
         on `Result.failure(e)`, emits `Result.failure(e)`.
